# Report U9 — 2026 Local-AI UX Best Practices: Topbar Residency Shield & Context Budget Meter

## Summary

Researched 2026 desktop local-AI UX patterns across LM Studio (`https://lmstudio.ai/docs/app`, checked `2026-11-18`), Ollama (`https://docs.ollama.com`, checked `2026-11-18`), Jan (`https://docs.jan.ai`, checked `2026-11-18`), Open WebUI (`https://docs.openwebui.com`, checked `2026-11-18`), and the Model Context Protocol host security guidelines (`https://modelcontextprotocol.io`, checked `2026-11-18`), audited SPIKE's chat shell against those patterns, and implemented a zero-dependency **Local Residency & Context Budget Pill (`LocalTrustBar`)** in the main topbar.

## Why This Fits SPIKE

1. **Always-visible data-residency & file-boundary status**: Previously, `App.tsx` showed `llama-server` status only at the bottom of the collapsible sidebar (`!sidebar` hid it completely) and gave no top-level indicator when the active provider switched to a remote API or when `share_files` was enabled vs withheld.
2. **Surfacing live telemetry already computed by `GET /api/runtime`**: `LlamaCppServer.status()` (`spike/runtime/llamacpp_server.py`) already returned `context` and `rss_mb`, but `App.tsx` typed `engine` as `{ running: boolean } | null` and discarded both fields.
3. **Proactive context-overflow transparency**: Instead of surprising users only after `context_trimmed` fires mid-run (especially on CPU-only `8,192`-token windows), `LocalTrustBar` displays an honest `~estimated` (`~4 chars/token`) `role="meter"` context bar with `>= 75%` (`warn`) and `>= 90%` (`high`) guidance, plus active specialist execution mode (`Accepted LoRA adapter loaded` vs `Instruction and tool profile` vs `Automatic router`) and a one-click jump to `Settings → Local engine` or `Settings → Providers`.

## Files Changed

- `web/src/localTrust.ts` — Pure snapshot & character estimation helpers (`computeTrustSnapshot`, `estimateThreadChars`).
- `web/src/components/LocalTrustBar.tsx` + `web/src/components/LocalTrustBar.css` — Accessible topbar pill (`aria-expanded`, `aria-controls`, `role="meter"`, `Escape` focus restoration, outside-click dismissal, reduced-motion & light/dark token compliance).
- `web/src/i18n.ts` — Full Spanish and English `localTrust` dictionary keys with exact key and `{placeholder}` parity.
- `web/src/App.tsx` — Widened `engine` state to `RuntimeSnapshot | null` and mounted `<LocalTrustBar />` in `.topbar`.
- `web/src/localTrust.test.tsx` — TDD unit and DOM accessibility suite (5 tests).
