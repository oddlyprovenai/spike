# U5: Página estática de GitHub Pages (`docs/site/`) sin trackers y con demo interactiva simulada

## Resumen
Se ha construido en `docs/site/` la web estática bilingüe (`index.html` en inglés y `es/index.html` en español, con `.nojekyll` y activos locales en `docs/site/assets/`) lista para publicar en GitHub Pages cuando el propietario lo autorice. Emplea la paleta propia de Oddly Proven (`#0E1116`, `#F7F5EF`, `#88D445`, `#F0592A`, `#3B82F6`, `#E5484D`) con contraste WCAG AA verificado, aplica una cabecera `Content-Security-Policy` con `connect-src 'none'` (cero peticiones externas, cero cookies y cero scripts de seguimiento) e incorpora un reproductor interactivo accesible por teclado (`role="tablist"` / `role="tabpanel"` / `aria-live="polite"`, respetando `prefers-reduced-motion`) con prompt `lab@mac-studio ~ %` que recorre la instalación en 3 comandos, el router léxico de ~1 ms (`116/130 = 0.89`), los veredictos de Medicina Ronda 1 -> Ronda 2 (con la advertencia explícita de las `409/1,000` respuestas base sin parsear en MedMCQA) y el rechazo de Finanzas Rondas 1 y 2.

## Criterios
- Página estática para GitHub Pages sin trackers ni peticiones externas: **cumplido** (`tests/test_pages_u5.py::test_docs_site_files_exist_with_zero_trackers_and_strict_csp`).
- Paleta Oddly Proven con contraste WCAG AA y cero colores de marcas externas: **cumplido** (`tests/test_pages_u5.py::test_oddly_proven_palette_and_wcag_aa_contrast`).
- Demo interactiva simulada con prompt `lab@mac-studio ~ %` y cifras estrictas de `STATUS.md` / `FACT-SHEET.md`: **cumplido** (`tests/test_pages_u5.py::test_simulated_terminal_replay_and_honest_figures`).

## Decisiones
- Se ubica en `docs/site/` (sin tocar `site/` de `G31`, que mantiene su propio contrato sin `<script>` en `tests/test_site_g31.py`), de modo que ambos enfoques coexisten limpiamente y Claude puede elegir qué carpeta servir cuando el propietario apruebe activar GitHub Pages.
- No se añade ningún workflow automático de despliegue a GitHub Pages (publicar requiere aprobación escrita del propietario).

## Pendiente
- Activar GitHub Pages en los ajustes del repositorio cuando el propietario dé su OK escrito (`L3`).
