Install in 3 Commands

Runs strictly on 127.0.0.1. Add --no-model to skip the 2.74 GB weight download or --dry-run to preview every command without touching your system. 

lab@mac-studio ~ % git clone https://github.com/oddlyprovenai/spike.git && cd spike
lab@mac-studio spike % ./scripts/install.sh --yes
lab@mac-studio spike % spike serve --open

Windows PowerShell 5.1 / 7: powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Yes. Full bilingual documentation: User Guide (EN) · HTTP API Reference.

What SPIKE Does Not Claim

  • 12 of 13 specialists have no accepted adapter yet: they run as transparent β prompt profiles on Qwen3.5-4B until their own statistical gate passes.
  • No head-to-head superiority claims: Ollama, LM Studio, Open WebUI, and Jan were not benchmarked here; see the sourced architecture table in README.md.
  • Not professional advice or a medical device: Medicine, Finance, Law, and Security outputs are general technical information only.
  • Zero telemetry & strict CSP on this page: connect-src 'none' is enforced in the HTML header — zero cookies, zero tracking scripts, zero third-party requests.
